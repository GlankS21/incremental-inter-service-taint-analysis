# Project

- `ecommerce/` — Spring Boot microservices (testbed for the VKR).
- `analysis/` — inter-service taint analysis tooling (Micans/Tai-e plugins, channel-extractor, summaries).
- VKR topic: incremental inter-service taint analysis for Java microservices in CI/CD.

# Skills

Invoke the matching skill before starting the task, without waiting for the user to type it.

## Analysis tooling (`analysis/`, thesis method)

| Task | Skill |
|---|---|
| Design of incremental recomputation, CI integration, summary/channel model; any design trade-off | `engineering:architecture` |
| Overall pipeline / component layout of the tool | `engineering:system-design` |
| Building Micans/Tai-e, JDK toolchain, ASM upgrade, Gradle/Maven failures | `java-backend-skills:java-build` |
| Analysis crashes, missing/unexpected flows whose cause is unclear | `java-backend-skills:java-debugging` |
| Analysis runtime, PTA memory/time, scaling measurements | `java-backend-skills:java-performance` |
| Experiment plan: seeded vulns, precision/recall, comparison with Micans | `engineering:testing-strategy` |
| Charts of experiment results | `dataviz` |
| README / tool documentation | `engineering:documentation` |
